# Decisões

Decisões arquiteturais e técnicas do projeto (ARQ-04, DEV-11).

- Um arquivo por decisão: `ADR-NNN-titulo.md`, a partir de `.claude/skills/playbook-plan/templates/adr.md`.
- Estados: Proposta, Aprovada, Substituída, Revogada. Decisões antigas permanecem; não apague.
- `precedentes-de-risco.md`: classificações de risco aprovadas que podem orientar mudanças equivalentes (DEV-05 §11 e §12). Crie quando houver a primeira.
